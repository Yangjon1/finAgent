# 7. 前端设计

## 7.1 菜单

```text
工作台
├─ 我的待办
├─ 报销管理：报销申请、我的报销、发票中心
├─ 合同管理：合同列表、合同分析、风险台账
├─ 审批中心：待我审批、我已审批、流程配置
├─ 预算与财务：预算总览、预算执行、付款记录
├─ 知识库：制度文档、合同条款、检索测试
├─ Agent 运行：运行记录、人工复核
├─ 数据看板：金额、时效、风险和预算图表
└─ 系统管理：用户、角色、部门、审计日志
```

## 7.2 关键页面

报销详情页用步骤条展示“材料—解析—校验—风险—审批—付款/归档”，每个 AI 字段显示来源文件、页码、置信度和可人工修正入口。审批页固定展示金额、规则命中、预算余额、风险证据、历史审计和操作按钮。

合同分析页展示版本、条款列表、缺失必备条款、风险等级、原文定位和修改建议；禁止只展示模型结论而隐藏证据。

## 7.3 状态与交互

Pinia 保存用户、权限和短期页面状态；服务端状态通过 API/轮询或 SSE 更新。提交后显示处理中，失败时提供重试或转人工；任何不可逆操作要求确认并填写原因。Element Plus 负责表格、表单、Drawer、Steps、Tag、Dialog；ECharts 用于预算执行、风险分布、审批漏斗和趋势。
