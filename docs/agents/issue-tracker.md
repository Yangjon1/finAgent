# Issue tracker: GitHub

Issues and specs for this repository live in [GitHub Issues](https://github.com/Yangjon1/finAgent/issues). Use the `gh` CLI for issue operations.

## Repository

- Remote: `https://github.com/Yangjon1/finAgent.git`
- Owner: `Yangjon1`
- Repository: `finAgent`

## Conventions

- Create: `gh issue create --title "..." --body "..."`
- Read: `gh issue view <number> --comments`
- List: `gh issue list --state open`
- Comment: `gh issue comment <number> --body "..."`
- Labels: `gh issue edit <number> --add-label "..."`
- Close: `gh issue close <number> --comment "..."`

PRs are not treated as a triage request surface by default.
